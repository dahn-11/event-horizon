# Event Horizon EX - VS Code Theme

### Welcome to the **Event Horizon EX** theme — where coding meets cosmic domination.

This theme is designed to take your VS Code environment beyond the event horizon, where only kings like you can reign. Customize your coding experience with deep, dark hues, and sharp contrasts, perfect for focusing on your craft while basking in the glow of your limitless potential.

## Features
- **VS Dark Mode**: Dark, immersive color scheme that's easy on the eyes for long coding sessions.
- **Cosmic Vibes**: A mix of deep blues, purples, and other dark tones, with electric highlights that make your code pop.
- **High Contrast**: Syntax highlighting designed to bring your code to life, with a focus on readability and visual flow.
- **Perfect for Coders with Ego**: You know you're at the top of your game, and your theme should reflect that level of dominance.

## Installation

To install this theme:

1. Download the `.vsix` file from the release.
2. Open VS Code.
3. Press `Ctrl + Shift + P` (or `Cmd + Shift + P` on macOS) to open the command palette.
4. Type `>Developer: Install Extension from VSIX...`.
5. Choose the `event-horizon-<version>.vsix` file.
6. Your new theme will be available under the **Color Theme** selector.

## Usage

1. Press `Ctrl + Shift + P` (or `Cmd + Shift + P` on macOS).
2. Type `Color Theme` and select **Event Horizon** from the list.
3. Enjoy the dark, endless space around you as you code at the top of your game. 

## Customization
